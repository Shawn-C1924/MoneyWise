# MoneyWise

MoneyWise is a mobile-first personal budgeting and savings-planning Progressive Web App.

## Project aim

MoneyWise helps users track discretionary spending, manage planned essentials, carry unused allowances forward, review monthly performance, edit budgets, and model savings outcomes over a configurable timeframe.

The interface offers Light, Dark, and the signature Iconic green theme, with compact icon-based controls designed for a clean mobile experience.

## Privacy

This public repository contains generic application code and assets only.

Personal financial assumptions are not embedded in the public source. On first launch, users enter their own planning values; these are stored locally on the device/browser.

Do not commit private exports or screenshots containing personal financial information.

## Running

Host the static files on GitHub Pages or another HTTPS static host. On iPhone, open the site in Safari and use **Share → Add to Home Screen**.

## Files

- `index.html` — app interface and logic
- `manifest.webmanifest` — PWA metadata
- `sw.js` — offline cache
- `icon-192.png` / `icon-512.png` — Home Screen icons
- `README.md` — project documentation
